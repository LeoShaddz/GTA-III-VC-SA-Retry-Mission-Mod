# GTA III/Vice City/San Andreas Retry Mission Mod

This mod allows you to quickly restart a mission if you fail it. This mod have controller support.

Here’s how it works: When you fail a mission, the game pauses, and you can choose whether or not to restart it. If you choose not to, the game unpauses and you continue playing as usual. If you choose to restart, the game unpauses, and your:

Health
Armor
Money
Wanted level
Ammo
Time of day
Weather
Appearance (VC/SA)
Stats (SA) 

are all restored to the state they were in when you started the mission, you are then teleported to the mission marker.

You can customize the text on the "Retry" screen, which makes it possible to translate the text into another language, and you can also adjust the time it takes for the restart screen to appear.

# Installation

**III**:

1. Install the Ultimate Asi Loader in in the game's root folder
2. Extract the file "III.Retry.Mission.Mod.v1.0.zip"
3. Copy the "Retry Mission Mod" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**VC**: 

1. Install the Ultimate Asi Loader in in the game's root folder
2. Extract the file "VC.Retry.Mission.Mod.v1.0.zip"
3. Copy the "Retry Mission Mod" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**SA**: 

1. Install the Silent's Asi Loader and Modloader in in the game's root folder
2. Extract the file "SA.Retry.Mission.Mod.v1.0.zip"
3. Copy the "Retry Mission Mod" folder into the "modloader" folder, which is located in your game's root directory.
4. Done
